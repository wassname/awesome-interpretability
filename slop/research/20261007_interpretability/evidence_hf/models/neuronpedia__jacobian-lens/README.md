This folder contains pre-fitted Jacobian Lenses for specific models. They were trained using Anthropic's [Jacobian Lens](https://github.com/anthropics/jacobian-lens) library. The same library can be used to load the lens and local visualizer.

Jacobian Lens can be explored on Neuronpedia at [https://neuronpedia.org/jlens](https://neuronpedia.org/jlens).
