<p align="center"><h1>Concept16K for Supervised Dictionary Learning (SDL)</h1></p>

Concept16K contains training and inference data for 16K concepts randomly sampled from the released `GemmaScope` concept list for `Gemma-2-2B-it` at 20, and `Gemma-2-9B-it` at layers 20.

**At the time of our AxBench release, Concept16K is by far the largest supervised dictionary learning (SDL) dataset for LLMs.**

**Cost:** With our initial implementation, construct training data for each concept costs less than $0.01 with 72 positive examples and 72 negatives.

Each subset comes with the following format:
- `input`: Instructions sampled from publicly available instruction-tuning datasets for three genres: *text*, *code*, and *math*.
- `output`: Model or LLM-generated responses. If `output_concept` is not `EEEEE`, then the `output` is generated by the LLM and contains the concept indicated in `output_concept`. Otherwise, it is a model-generated response.
- `output_concept`: The concept contained in the `output`. `EEEEE` means no concept.
- `concept_genre`: *text*, *code*, and *math*.
- `category`: *negative* means no concept is in the output. Otherwise, it should be `positive`.
- `dataset_category`: Since this dataset is for instruction-tuned models, it should always be equal to `instruction`.
- `concept_id`: The globally unique ID of the `output_concept`. We use this to match the subspace index in the saved dictionary.

Other dataset statistics can be found in our paper.
